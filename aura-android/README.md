# AURA pr0.73-4 Android project

Complete decoded Apktool project used to build AURA pr0.73-4.
Includes Android resources, assets, native libraries and Smali sources.
Build with Apktool 3.0.3: `java -jar apktool.jar b aura-android -o AURA-pr0.73-4-unsigned.apk`.

This is a complete decompiled/rebuildable project, not the upstream Kotlin/Java Gradle source repository.
