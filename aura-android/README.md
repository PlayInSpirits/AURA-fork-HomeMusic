# AURA 0.5-1 Android project

Complete decoded Apktool project used to build AURA 0.5-1.
Includes Android resources, assets, native libraries and Smali sources.
Build with Apktool 3.0.3: `java -jar apktool.jar b aura-android -o AURA-0.5-1-unsigned.apk`.

This is a complete decompiled/rebuildable project, not the upstream Kotlin/Java Gradle source repository.
