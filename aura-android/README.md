# AURA 0.3 Android project

This is the complete decoded Apktool project used to build AURA 0.3.
It includes the Android manifest, all resources, assets, native libraries and Smali sources.
Build with Apktool 3.0.3: `java -jar apktool.jar b aura-android -o AURA-0.3-unsigned.apk`.

This is a complete decompiled/rebuildable project, not the upstream Kotlin/Java Gradle source repository.
The original HomeMusic project is linked from the root README.
