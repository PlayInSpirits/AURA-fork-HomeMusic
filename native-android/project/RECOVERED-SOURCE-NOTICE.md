# Recovered Android source baseline

This is a recovered Android project built from AURA 0.75.1 using JADX 1.5.6 structured Java (type-update-limit 100) and Apktool resources; it is not the original author's source tree. Some methods may be partially decompiled and must be cross-checked against the accompanying Apktool Smali reference. AndroidX and Material sources are restored as Maven dependencies using embedded version markers.

The application ID is preserved as app.homemusic; display version is v0.10.1 and versionCode is 7502. Do not publish a release from this baseline until Gradle builds, signature compatibility, data migration, and Hub/Navidrome acceptance tests pass.
